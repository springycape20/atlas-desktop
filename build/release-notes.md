ATLAS 0.6.13 fixes where Colab shows a disagreement between Codex and Claude.

- When Codex and Claude disagree, the choice between them now appears directly above the message box. In 0.6.12 the "Codex is right" / "Claude is right" buttons were inside the collapsed Run details section, so you could see the message asking you to choose but not the buttons to answer it.

Install over your existing version to preserve conversations and settings. Packaged installations can use **Settings > App updates > Check for updates**, then download and restart to install.
