ATLAS 0.11.0 makes project work easier to navigate, review and control, and adds a clear launch prompt for available updates.

**If you are on 0.10.2 or older, download the installer below.** In those versions **Restart and install** fails with an "Invalid package" error. Installing over your existing version preserves conversations and settings. Newer versions can use **Settings > App updates**; if that fails, use the installer instead.

- **Updates:** enable Automatically download updates in Settings > App updates to download releases in the background. It is off by default. The launch prompt offers Download update or Later, then Restart and install when ready. ATLAS never restarts automatically and retains its running-work and recovery checks.
- **Clearer navigation:** searchable tool navigation, focused preview views, editor File/Edit/Code/View menus and compact secondary-action menus replace crowded rows of buttons. Ctrl+K reaches pages, tools, settings and chats.
- **Long conversations:** Assistant and Colab render 150 messages per page, with older/newer controls and search across saved messages, including those outside the displayed page.
- **Editor intelligence:** use an approved, already installed language server for draft-aware definitions, references, diagnostics, hover information, plain-text completion and previewed, conflict-protected text renaming.
- **Browser and visual checks:** build repeatable browser steps, wait for text or visibility with timeouts, and save named project-scoped visual baselines across restarts.
- **Background backups:** archive creation runs in a cancellable worker with progress. Choose an external automatic-backup folder or Back up now. Archives are compressed, not encrypted; external copies survive local-data reset.
- **Task budgets:** optional project limits for duration, ATLAS invocations, repair passes and estimated outgoing text pause tasks when exhausted. These are not monetary or subscription spending caps.
- **Trial promotion:** preview selected text-file additions, edits and deletions before applying them to the original project. Conflicts and newer edits are protected, with bounded durable undo records.
- **Workflow benchmarks:** compare fixed tasks and pinned models in fresh checkpoint copies after approving a batch. Inspect executed checks, duration and available token reports, cancel runs or export results. Real runs use your provider accounts; unknown usage remains unknown.
- **Packaging:** no new dependencies, publisher telemetry or automatic uploads. The existing unsigned-release policy remains in effect, so Windows may show a warning. No legal or security certification is claimed.

Windows x64. Close older ATLAS instances before installing. Computer control uses the separate Windows-MCP integration, not another chat application's private runtime.
