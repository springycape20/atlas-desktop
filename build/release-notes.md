ATLAS 0.9.1 adds project previews and tools for reviewing and navigating your work.

- **Images and files in chat.** Chat and Colab display local project images and clickable file references. Browse folders, search filenames or file contents, preview text and static HTML, and attach project files to an unsent message. Keep the browser beside chat to drag files into the composer.
- **Live project preview.** Open a local HTTP development server in an isolated preview window beside chat. Installed Vite projects can start on loopback after confirmation; other servers can be started separately. View server output and open recognised source locations from errors.
- **Visual feedback.** Select an element in the live preview and attach its screenshot and selector to an unsent feedback draft. Preview pages have no ATLAS API, device permissions, downloads or cross-origin requests.
- **Review and recovery.** Completion reports combine changed files, executed checks and model review evidence, with a follow-up draft action. Named text checkpoints support selected-file comparison, explicit restore confirmation, conflict protection and a recovery snapshot.
- **Context and project health.** See an approximate optional-context token count and prepare a handover summary request. Local health checks find project manifests, tools on PATH and dependency folders, with suggested checks. These checks do not install packages or run project scripts.
- **Accessibility.** A reduced-motion preference joins the existing text-size, contrast, spacing and keyboard controls.
- **Dependency maintenance.** Updates the MCP SDK's transitive @hono/node-server dependency to 2.1.5; the production advisory audit reports zero vulnerabilities.
- **Limits and permissions.** Automatic server startup currently supports installed Vite projects. Live previews accept loopback HTTP URLs and block other origins. Static HTML previews keep scripts disabled. Text checkpoints are bounded snapshots, not full backups. Provider-managed compaction is not exposed to ATLAS. Screenshots/files reach a provider only when you send the attached message.
- **Unsigned release.** The existing owner-approved unsigned release policy remains in effect. Windows may warn. Technical checks and model review do not constitute legal certification or guarantees of correctness.

Install over your existing version to preserve conversations and settings. Packaged installations can use **Settings > App updates > Check for updates**, then download and restart to install. Windows x64. Close older ATLAS instances before updating. Computer control uses the separate Windows-MCP integration, not another chat application's private runtime.
