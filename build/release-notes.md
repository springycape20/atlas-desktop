ATLAS 0.10.1 adds more efficient context handling and reviewed local work sessions.

- **Context and model usage:** inspect a request-text budget, reuse unchanged references only in confirmed retained Assistant sessions, and optionally allow one stronger-model repair after executed checks fail on changed files. The repair reruns checks. Estimates do not measure remaining subscription allowance or guarantee token savings.
- **Checkpoint trials:** capture a bounded project checkpoint, try isolated alternatives, compare their files and export a preferred trial into an empty project folder. Dependencies, Git history, private paths and common generated folders are excluded. Trial folders live in ATLAS data and must be exported before resetting it.
- **Project understanding:** browse a static project map, inspect linked source files, track context freshness and prepare selected local excerpts/checks before contacting a model. Scans are bounded; dynamic relationships can be missed.
- **Review and continuity:** reviewed milestone handovers can explicitly target Codex or Claude in a fresh unsent chat. The review inbox gathers retained checks, changes, questions, requirements and approvals. Acceptance evidence distinguishes model/user claims from linked executed-check results.
- **Reusable work:** save ordered recipe steps and stopping-condition instructions, search previous local task/check/diff evidence, and reuse only reviewed excerpts. Existing permissions and Colab verification gates remain in effect.
- **Diagnostics:** focused failure excerpts reduce successful-log noise while bounded local completion-check logs remain available for inspection. Bug-report exports include reproduction/expected/actual behavior, optional selected evidence, heuristic redaction and explicit review. Nothing uploads automatically.
- **Documentation and packaging:** updated feature/privacy guides, screenshots and notices. No new dependencies or publisher telemetry. The existing unsigned-release policy remains in effect.

Install over your existing version to preserve conversations and settings. Packaged installations can use **Settings > App updates > Check for updates**, then download and restart to install. Windows x64. Close older ATLAS instances before updating. Computer control uses the separate Windows-MCP integration, not another chat application's private runtime.
