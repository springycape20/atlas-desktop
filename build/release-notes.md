ATLAS 0.8.3 improves security, privacy controls and third-party licence disclosures.

- **Voice and licences.** Bundled Kokoro and its eSpeak/ONNX/native-image dependencies are removed while source and licensing questions remain unresolved. Existing Kokoro selections switch to Windows speech. Optional ElevenLabs remains available. Third-party notices, a dependency inventory and privacy information are included in the app; open them from Settings → Tools and data.
- **Microphone controls.** Wake-word, automatic follow-up and interruption listening require opt-in. Older automatic-listening defaults are reset. The microphone indicator pauses automatic capture.
- **Safer permissions and credentials.** Remembered PowerShell permission asks again for dynamic/obfuscated commands and nested shells. Project programs can still change files; remembered permission is not a sandbox. Claude usage now links to the provider page without reading sign-in tokens. Tool-runtime downloads are pinned and checksum-verified.
- **Local data controls.** Export a diagnostic log with common credential patterns redacted, or confirm a restart to delete current ATLAS records. Review exports before sharing. Downloaded tool runtimes, external projects, Git snapshots, exports, legacy folders and provider histories have separate retention.
- **App hardening and maintenance.** ASAR integrity checks, private-file packaging exclusions, dependency advisory checks and private security reporting are enabled. Chat-list storage failures are handled, Stop has real PowerShell fixture coverage, and Colab typography and screenshots are refreshed.
- **Unsigned release.** SignPath declined the project because it has no active users. This installer is unsigned and Windows may warn. No signing approval, legal certification or guarantee against claims is implied. AI replies and reviewer acceptance can still be wrong.

Install over your existing version to preserve conversations and settings. Packaged installations can use **Settings > App updates > Check for updates**, then download and restart to install. Windows x64. Close older ATLAS instances before updating. Computer control uses the separate Windows-MCP integration, not another chat application's private runtime.
