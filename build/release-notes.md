ATLAS 0.10.5 adds chat folders, automatic backups, edit and resend, and easier ways to review what ATLAS keeps.

**If you are on 0.10.2 or older, download the installer below.** In those versions **Restart and install** fails with an "Invalid package" error. Installing over your existing version preserves conversations and settings. If you are on 0.10.3 or 0.10.4, use **Settings > App updates**, and if that fails, use the installer instead.

- **Chats:** file chats in folders and archive them in Assistant and Colab. Edit and resend a message, or branch from one. Both start a new chat and leave the original unchanged.
- **Automatic backups:** on by default. ATLAS saves a copy of your local records once a day and keeps the newest seven in its data folder, so they use disk space. They are compressed, not encrypted. Turn them off in **Backups and recovery**.
- **Recovery cleanup:** review old recovery copies and delete them after confirming.
- **Memory review:** check and remove what ATLAS remembers.
- **Report a problem:** prepares a report for you to read and opens a blank GitHub issue. ATLAS sends nothing itself.
- **Tray and shortcut:** optional, under **Settings > Startup**, and off by default. With the tray on, closing the window keeps ATLAS running.
- **Packaging:** no new dependencies or publisher telemetry. The existing unsigned-release policy remains in effect, so Windows may show a warning.

Windows x64. Close older ATLAS instances before installing. Computer control uses the separate Windows-MCP integration, not another chat application's private runtime.
