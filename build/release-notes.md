ATLAS 0.9.0 adds project tools, clearer navigation and new controls for larger tasks.

- **Projects and context.** Optional bounded source indexing, context previews and exclusions, project-scoped editable memories, reusable workflows, and local text-model connections.
- **Planning and execution.** Editable task plans require approval before preparing an unsent Colab draft. Optional project environment recipes show their commands for approval before setup; read-only modes skip setup. Parallel batches use isolated workspaces and combined integration checks.
- **Review and recovery.** A unified review centre combines tracked files, executed checks, model review reports and protected rollback previews. Interrupted tasks load paused. Live progress shows stages and pending decisions; time estimates appear only with enough comparable history.
- **Model controls.** Opt-in fast/strong model tiers use your configured model IDs, with per-message overrides. Local-model hardware checks report available capacity and labelled estimates; they do not download a model or guarantee speed or compatibility.
- **A clearer interface.** Chat, Colab, Projects, Tasks, Library and Settings; consistent composers; resizable conversation lists; stage summaries; Dark, Light and High contrast themes; larger text; Ctrl+K navigation and Ctrl+Shift+F local work search. Provider activity replaces overlapping quota rings and distinguishes local tasks from account allowance.
- **Privacy and permissions.** Search and project tools use local records, with source excerpts opt-in. Memories, plans and setup recipes are not tool authorization. Provider accounts, optional integrations and local servers retain their own network behavior and terms. No publisher telemetry or new production dependencies were added.
- **Unsigned release.** The existing owner-approved unsigned release policy remains in effect. Windows may warn. Technical checks and model review do not constitute legal certification or guarantees of correctness.

Install over your existing version to preserve conversations and settings. Packaged installations can use **Settings > App updates > Check for updates**, then download and restart to install. Windows x64. Close older ATLAS instances before updating. Computer control uses the separate Windows-MCP integration, not another chat application's private runtime.
