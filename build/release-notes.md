ATLAS 0.10.0 expands local project tools and adds interactive terminals beside chat.

- **Interactive terminal dock:** multiple persistent PowerShell sessions, ANSI colours, resizing and interactive input. Fixes toolbar overlap, header alignment and typed commands jumping below the prompt. Initial PTY approval covers raw input for the session; the text-shell option retains per-submission confirmation.
- **Editing and previews:** editable tabs with stale-write protection, project find/replace preview, line numbers and basic editing helpers, broader preview recipes, PDF/DOCX text previews and selected PDF page attachments. No OCR or full document layout rendering.
- **Task verification and recovery:** selective diff sections, TAP/pytest/JUnit results, tool-version preflight, editable task prerequisites and graph, bounded repair attempts, task comparisons, completion evidence and recovery checks.
- **Project tools:** explained context ranking, static code intelligence, named multi-root workspaces, confirmed service starts and readiness checks, local Git staging/commits, and approved HTTP requests with one-time headers.
- **Privacy and control:** heuristic sensitive-context review, informational integration declarations, permission revocation and redacted diagnostic exports. Experimental statistics/Insights code was removed before release. No publisher reporting service or telemetry is included.
- **Backups and later updates:** compressed local-record backups, staged restore with current records retained, reviewed storage cleanup, and preserved-version recovery before future in-app updates. Backups are not encrypted and exclude external project worktrees and provider-owned histories. Updating from an older release uses that release's updater; the new recovery flow applies to later updates from 0.10.0.
- **Documentation and notices:** refreshed README/screenshots, feature and privacy guides, changelog and dependency notices. PDF extraction ships without optional native canvas or GPL fallback fonts. Heuristic checks and integration declarations do not create an OS sandbox or certify legal compliance.
- **Unsigned release:** Windows may warn because the existing owner-authorized unsigned policy remains in effect. Use this repository's release assets and review the documented permissions and limits.

Install over your existing version to preserve conversations and settings. Packaged installations can use **Settings > App updates > Check for updates**, then download and restart to install. Windows x64. Close older ATLAS instances before updating. Computer control uses the separate Windows-MCP integration, not another chat application's private runtime.
