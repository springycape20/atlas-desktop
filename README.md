# ATLAS downloads

Official Windows installers and update feed for ATLAS.

Download the latest stable installer from [Releases](https://github.com/springycape20/atlas-desktop/releases/latest). Sandbox previews are marked as pre-releases and do not charge real money.

This repository contains download information and release assets only. Ongoing application development is maintained in a private repository. Previously distributed MIT-covered software retains its licence permissions; bundled third-party notices accompany the installers. Windows installers currently remain unsigned.

Never post passwords, API keys, chats or private diagnostics in public issues.
