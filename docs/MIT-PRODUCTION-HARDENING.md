# MIT-compatible production hardening

Prepared 14 November 2026. This is local build work, not a new public release, trademark registration or guarantee against copying.

## Permissions and branding

The root MIT licence is unchanged. `NOTICE` preserves the ATLAS copyright and identifies third-party notices. `BRANDING.md` identifies official releases, encourages clear identification of independent builds, and expressly adds no restriction to MIT or existing artwork permissions. No mandatory interface credit, resale restriction, source-publication requirement or registered trademark claim has been added.

Protecting a brand is separate from controlling code reuse. A name/logo clearance and any trademark application remain separate decisions; no filing, payment or enforcement message was made. Existing MIT recipients retain their permissions. Minification cannot prevent lawful forks, reverse engineering or extraction, and the public GitHub repository still exposes the public source/history.

## Desktop build

`build/prepare-production.cjs` generates compliance materials and invokes `build/production-code.cjs` before electron-builder packages files. First-party root JavaScript, CommonJS workers and CSS are written to the ignored `dist/production-code/` staging directory. File mappings package those generated copies at their original runtime paths. Editable source is never rewritten. The pre-existing generated Prism bundle is copied exactly, including its full upstream licence.

Terser 5.51.2 and Clean CSS 5.3.3 are pinned development-only tools. JavaScript uses local-variable mangling without property or top-level mangling or compression transforms; function/class names stay intact for compatibility and diagnostics. Legal comments and the full ATLAS MIT notice remain. CSS retains relative paths, custom properties and legal comments. No source maps are generated, and package filters reject distributed `.map` files. These measures do not involve remote services, encrypted code loaders, runtime keys or restrictions on user permissions.

Binary fuses and ASAR integrity are applied normally after the staged files are packaged. The archive is not rewritten after its integrity hash is embedded. Required notices are present both in the archive and the compliance resources. `PRODUCTION-CODE.json` binds input hashes to generated hashes; package verification checks every first-party code file, copyright notice and absence of maps.

The 135 production dependency entries are unchanged. Nine new development package entries declare MIT or BSD-2-Clause. The dependency audit still reports existing moderate findings in the Electron build/runtime dependency graph; the added minifier packages are not among those findings. Do not apply an unrelated automatic dependency upgrade as part of this work.

## Website

The separate website keeps editable JavaScript/CSS in `src/` and builds minified output into `dist/`. Its production assets retain the full MIT notice, with local `LICENSE.txt`, `NOTICE.txt` and branding text available. The portable distribution includes generated public assets, not editable source or source maps. The local security audit checks output and ZIP contents.

The website was initially kept owner-only during the licensing review. The owner subsequently requested pushing the verified work to GitHub and reopening the updated website publicly. This authorizes website publication; it does not authorize a replacement desktop release under the existing tag. The custom domain remains atlasapp.net.co, and the application repository remains public.
